# إعادة بناء منصة فرع تنفيذ شمال الصعيد — أساس التطوير V0.1

## ما الذي تم تنفيذه فعليًا في هذه المرحلة؟
- تطبيق خادمي FastAPI مع قاعدة بيانات SQLite محلية مستمرة، وليس `localStorage`.
- تسجيل دخول خادمي بحسابات تجريبية وكلمات مرور مخزنة بصيغة PBKDF2، وجلسة موقعة.
- فتح كل وحدة في صفحة مستقلة عبر رابط جديد من مركز القيادة.
- وحدات اختبار: المواعيد، اللوحات الهندسية، التكليفات، المشروعات، المخازن، الأصول، القوى العاملة، المصروفات الطبية، الإجازات، الشكاوى.
- صلاحيات أساسية على الخادم وعلى واجهات API، بما فيها حجب بيانات المصروفات الطبية عن غير HR، وإتاحة ملخص القوى العاملة/الرواتب الإجمالي للأدوار المعتمدة فقط.
- منع إغلاق التكليف دون مرجع إثبات، وتسجيل الدخول/الخروج وإنشاء/تعديل السجلات في سجل مراجعة على قاعدة الاختبار.
- 11 سجلًا تجريبيًا واضح الوسم، بأسماء ومبالغ وأرقام مصطنعة.
- تصميم عربي RTL بألوان كحلي وذهبي وعاجي، وشعار V8 Gold.

## التشغيل على Windows
1. فكّي ضغط الحزمة في مجلد محلي.
2. ثبتي المتطلبات في بيئة Python مخصصة: `python -m pip install -r requirements.txt`
3. شغّلي `run_local.bat`.
4. افتحي `http://127.0.0.1:8765`.

## حدود صريحة
هذه **مرحلة أساس تطوير واختبار محلية وليست منصة إنتاج أو تسليم نهائي**. قاعدة SQLite محلية على الجهاز، ولا توجد استضافة مشتركة أو إشعارات بريد/رسائل أو ربط ERP أو GPS. مفتاح الجلسة الافتراضي مخصص للتطوير فقط ويجب استبداله من متغير بيئة قبل أي بيئة مشتركة. قواعد الصلاحيات أولية وتحتاج مراجعة أمنية واختبارًا أوسع، وسجل التدقيق ليس مخزنًا خارجيًا مقاومًا لمدير قاعدة البيانات. دورة الإجازات لا تخصم أرصدة، ولا تعتبر موافقات هذه العينة اعتمادًا إداريًا حقيقيًا. كل الأرقام والسجلات وهمية.
