# نموذج V19 — تطوير المخازن والتقارير

## ما تمت إضافته
- منظومة مخازن تفاعلية: بحث أصناف، أرصدة حسب المخزن، المحجوز والمتاح، الحد الأدنى، القيمة التقديرية، إضافة وصرف وتحويل، وطلب احتياج مرتبط بمشروع.
- سجل الحركات، سجل بدء جرد تجريبي، واستيراد/تصدير CSV متوافق مع Excel.
- لوحة تخطيط ومتابعة بمؤشرات توضيحية، بحث وفلترة حسب المحافظة والحالة، وبطاقة تفصيلية لكل مشروع.
- بطاقة المشروع: الموقف التنفيذي والمالي، المعوقات، الإجراء والمسؤول والموعد المستهدف.
- تحديث أسبوعي، سجل تحديثات، سجل إجراءات، وقالب تقرير شهري قابل للتصدير.
- البيانات والأرصدة والمشروعات والأسعار المعروضة تجريبية وليست بيانات فعلية للفرع.

## طريقة التجربة
1. فك الضغط مع الحفاظ على مجلد `assets` بجوار `index.html`.
2. افتح `index.html` في متصفح حديث.
3. أمين المخزن: `NEE-ST001` / `Store@2026`.
4. التخطيط والمتابعة: `NEE-PL001` / `Plan@2026`.
5. مدير الفرع: `NEE-MGR001` / `Manager@2026`، وله صلاحية النموذجين.

## حدود النموذج
- التخزين في `localStorage` بالمتصفح الحالي فقط؛ لا توجد قاعدة بيانات مشتركة أو خادم.
- الاعتمادات والإشعارات وسجل التدقيق الآمن غير مفعلة؛ كل الحركات والتحديثات مسودات تجريبية.
- استيراد/تصدير CSV فقط؛ من Excel اختاري CSV UTF-8. لا يدعم ملف XLSX مباشرة.
- يجب اعتماد مصدر البيانات وتعريف المؤشرات المالية قبل استبدال الأمثلة ببيانات فعلية.
- لم يتم النشر على الموقع أو GitHub.
