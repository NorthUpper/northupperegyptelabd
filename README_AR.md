# V33 — نموذج الحوكمة والاختبار لفرع تنفيذ شمال الصعيد

هذه نسخة تجريبية مبنية على النسخة المتكاملة السابقة، وتضيف مسارًا مرئيًا لاختبار طلبات المواعيد والتكليفات وسجل المراجعة، مع بيانات وهمية معلّمة بوضوح.

## التشغيل
- فك ضغط الحزمة كاملة مع الحفاظ على مجلد `assets`.
- شغّل `تشغيل_للتجربة_المحلية.bat` على Windows أو افتح الصفحات عبر خادم محلي.
- الصفحات الأساسية: `index.html` للموقع العام، `employee-portal.html` لبوابة الموظفين، `management-dashboard.html` للوحة الإدارة، `warehouse-reports.html` للمخازن والتقارير.

## بيانات الاختبار
- من لوحة الإدارة > مركز قيادة الفرع، اضغط «تحميل عينة اختبار وهمية» لإنشاء 3 طلبات APT-DEMO.
- جرّب تغيير الحالة ثم راجع سجل الحوكمة.
- أضف تكليفًا تجريبيًا بمسؤول وموعد؛ التغييرات تحفظ محليًا في المتصفح.
- جميع الأسماء والأرقام والمبالغ ونسب التنفيذ داخل النموذج وهمية أو أمثلة مرجعية قديمة؛ لا تستخدمها في قرارات فعلية.

## حدود مهمة
التخزين محلي في المتصفح، ولا توجد قاعدة بيانات مشتركة أو صلاحيات حقيقية أو رسائل إشعار أو سجل تدقيق معتمد. لكي ينتقل طلب من الموقع العام إلى لوحة الإدارة يجب تشغيل الصفحات على نفس الأصل/المتصفح. لا تنشر النسخة ولا تدخل بيانات حقيقية قبل تنفيذ backend ومراجعة أمنية واختبارات قبول.

اقرأ `QA_REPORT_AR.md` و`GOVERNANCE_RECOMMENDATIONS_AR.md` و`TEST_DATA_REGISTER_AR.md` قبل التجربة.
