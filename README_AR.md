# V26 — النسخة المرشحة للمراجعة النهائية قبل الرفع

## الحالة بوضوح
هذه حزمة مراجعة نهائية مرشحة وليست اعتمادًا للتشغيل الرسمي. لم يتم رفعها إلى الموقع المباشر أو GitHub. التصميم والصفحات موجودة محليًا، لكن بوابة الموظفين ونموذج التواصل ما زالا تجريبيين ويعتمدان على المتصفح، لذلك لا يجوز استخدام بيانات حقيقية أو اعتبار الطلبات مرسلة للفرع.

## تشغيل ومراجعة النسخة
1. فك الضغط بالكامل في مجلد واحد.
2. افتح `index.html` لمراجعة الموقع العام.
3. افتح `employee-portal.html` لمراجعة مدخل بوابة الموظفين.
4. يُفضّل تشغيل خادم محلي موحد عند اختبار مشاركة البيانات بين الصفحات، لأن سلوك `localStorage` مع `file://` يختلف حسب المتصفح.
5. راجع `RELEASE_REVIEW_AR.md` و`QA_REPORT_AR.md` قبل اتخاذ قرار الرفع.

## المحتويات
`index.html` الموقع العام، `employee-portal.html` مدخل البوابة، `warehouse-reports.html` الخدمات الداخلية التجريبية، `hr-portal.html` رابط توافق، و`assets/` الصور والشعار.

## قيد جوهري قبل التشغيل الفعلي
المصادقة والأدوار داخل JavaScript، والبيانات محلية في المتصفح، ولا توجد قاعدة بيانات مشتركة أو صلاحيات خادمية أو إشعارات فعلية. يلزم تطوير backend ومصادقة آمنة وصلاحيات من جهة الخادم وقاعدة بيانات ونسخ احتياطي وسجل تدقيق واختبارات قبول قبل إدخال بيانات موظفين حقيقية.
