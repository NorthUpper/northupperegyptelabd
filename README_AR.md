# منصة فرع تنفيذ شمال الصعيد — V30

## الحالة
**مرشح لتجربة تشغيل محدودة ببيانات وهمية فقط، وليس جاهزًا لتشغيل إنتاجي ببيانات الشركة.** هذه النسخة تجمع الموقع العام وبوابة الموظفين والنماذج الأولية للموارد البشرية والمخازن والتقارير والأصول والحركة ومتابعة اللوحات الهندسية. لم يتم رفعها إلى الموقع الحي أو GitHub.

## التشغيل المحلي
1. فك الضغط بالكامل في مجلد جديد.
2. شغّل `تشغيل_للتجربة_المحلية.bat` على Windows (يتطلب Python)؛ يفتح خادمًا محليًا على `http://127.0.0.1:8000`.
3. راجع `index.html` للموقع العام و`employee-portal.html` لبوابة الموظفين.
4. راجع `V30_READINESS_REVIEW_AR.md` و`QA_REPORT_AR.md` قبل أي قرار بالنشر.

## حسابات الاختبار
- التخطيط والمتابعة: `NEE-PL001` / `Plan@2026`
- مدير الفرع: `NEE-MGR001` / `Manager@2026`
- مدير المحافظة: `NEE-GOV001` / `Gov@2026`
- الموارد البشرية: `NEE-HR001` / `HR@2026`
- تقنية المعلومات: `NEE-IT001` / `IT@2026`

هذه حسابات تجريبية مكشوفة داخل ملفات الواجهة وليست آمنة؛ لا تُرفع كما هي إلى موقع عام ولا تُستخدم لحسابات حقيقية. غيّر آلية المصادقة إلى خادم آمن قبل التشغيل الفعلي.

## القيود التشغيلية الجوهرية
- البيانات محفوظة في `localStorage` على المتصفح؛ لا توجد قاعدة بيانات مشتركة أو مزامنة بين الأجهزة.
- لا توجد إشعارات خادمية مضمونة تعمل بعد إغلاق الصفحة. إشعارات المتصفح المحلية ليست بديلًا عن خدمة تنبيه مركزية.
- صلاحيات الواجهة التجريبية ليست ضوابط أمنية؛ لا تُدخل بيانات رواتب أو بيانات شخصية أو مالية حقيقية.
- نماذج التواصل وطلبات المواعيد تجريبية ولا تصل إلى الفرع فعليًا.
- الأرقام والصور التوضيحية ليست بيانات تشغيلية معتمدة.

## متطلبات الانتقال للإنتاج
يلزم Backend وقاعدة بيانات مشتركة، ومصادقة آمنة، وصلاحيات تُفرض على الخادم، وسجل تدقيق غير قابل للتعديل من المستخدم العادي، ونسخ احتياطي واستعادة مجرّبان، وإشعارات مركزية، وإدارة أسرار، واختبارات أمنية وقبول المستخدمين، واعتماد رسمي للبيانات والمحتوى.
